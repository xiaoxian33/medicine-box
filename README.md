# 🌌 Cyber-Tunnel · 健康状态与心路分享社区

> 🕹️ 一款复古像素 / 赛博风「用药记录 · 心情分享 · 过量预警」一站式社区

欢迎光临。这里不是普通的药箱，而是一条通往自我健康管理的 **赛博隧道** 🚇。

Cyber-Tunnel 致力于帮助每个人**记录、统计、沟通**属于自己的**正常用药**与**非正常用药（过量 OD）**情况。你可以把它想象成一个「药品记账本 + 心情日记 + 社区广场」的结合体——既保护隐私地管理自己的健康数据，也能在公开区与更多伙伴交流。

---

## ✨ 核心亮点

- 🎨 **复古像素赛博风**：全套 Y2K 像素风格界面，可爱的操作系统模拟窗，点开即是回忆杀。
- 💊 **正常 / 过量（OD）用药区分**：每次记录可标记「本次为正常用药」与否，OD 会被自动识别并标红警示、触发全屏特效。
- 📊 **OD 数据看板**：按 7 / 14 / 30 天统计过量次数、本周 vs 上周趋势对比、连续记录天数。
- 💊 **用药方案一键登记**：预设多种药 + 剂量的方案，需要时一键批量登记，省心省力。
- 🌐 **社区共享流**：可公开自己的记录，逛逛来自所有用户的最新健康动态。
- 💬 **点赞 & 评论**：在每一条记录下都可以互动交流。
- 🧠 **心情轨迹**：滑动记录当天心情值，回溯自己的情绪曲线。
- 📌 **备忘录**：随手记录、回顾，还能一键清空。
- 🎵 **内置 BGM 播放器**：像素磁带试图，记录时也可以有点氛围感。
- 👤 **登录 / 注册**：专属账号，数据隔离，安全可靠。

## 🚀 快速开始

### 环境要求

- JDK 17+
- Maven（项目自带 `mvnw` 包装器）
- MySQL 8.x

### 1. 准备数据库

启动 MySQL 并创建一个数据库（JPA 会 `ddl-auto=update` 自动建表）：

```sql
CREATE DATABASE cyber_tunnel_db;
```

### 2. 修改数据库连接配置

编辑 `src/main/resources/application.properties`，把用户名密码改成你自己的：

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/cyber_tunnel_db
spring.datasource.username=root
spring.datasource.password=你的密码
```

### 3. 启动后端

```bash
# Windows
mvnw spring-boot:run

# macOS / Linux
./mvnw spring-boot:run
```

后端默认运行在 **http://localhost:8080**

### 4. 使用页面

- 社区主页：**http://localhost:8080**（未登录会自动跳转到登录页）
- 登录 / 注册页：**http://localhost:8080/login.html**

在登录页注册一个新账号即可进入社区。

## 📖 功能一览

### 💊 用药记录（核心）
- 填写药品种类、本次片数、吃药时间、分享设置（私密 / 公开）。
- 勾选「本次为正常用药」代表正常剂量；**不勾选 = 过量（OD）**。
- OD 记录会被标红、附上 🚨 徽章，并在登记后触发两分钟的屏幕震颤动效。

### 📊 OD 数据看板
- 近 7 / 14 / 30 天 OD 次数。
- 本周 vs 上周 OD 次数对比与趋势（进步 / 退步 / 持平）。
- 连续有记录的天数。

### 💊 用药方案
- 创建带名称和多种「药名 × 片数」的方案。
- 「一键登记」把所有药物按当前时间批量记录为一次正常用药。
- 支持删除单个方案 / 清空全部。

### 🌐 社区共享流
- 「私人」页签看自己的记录；「公开」页签浏览全员最新动态。
- 每条记录可点赞、评论，自己的评论可删除。

### 📌 备忘录
- 写记录 / 历史记录双页签，按时间倒序展示，支持逐条删除或一键清空。

### 🧠 心情记录
- 拖动滑块直观记录心情值，生成情绪气泡并保留历史。

### 🔒 用户系统
- 注册、登录、记住当前用户、退出登录。数据按用户隔离。

## 📁 项目结构

```
medicine-box-main
├─ pom.xml
├─ mvnw / mvnw.cmd
└─ src/main
   ├─ java/com/overdose/cyber_tunnel
   │  ├─ controller/   # 各业务 REST 控制器
   │  ├─ service/      # 业务逻辑层
   │  ├─ model/        # JPA 实体
   │  ├─ repository/   # Spring Data 仓库
   │  └─ config/       # 配置（Jackson 等）
   └─ resources
      ├─ application.properties   # 数据库等配置
      └─ static/                 # 前端页面与素材（index.html / login.html 等）
```

### 主要 API

| 方法 & 路径 | 说明 |
| --- | --- |
| `POST /api/users/register` | 注册用户 |
| `POST /api/users/login` | 登录 |
| `GET /api/users` | 用户列表（昵称映射用） |
| `GET/POST/PATCH/DELETE /api/medications...` | 用药记录增删改查、心得更新、归档 |
| `GET /api/medications/public` | 公开记录流 |
| `GET /api/medications/stats/od` | OD 过量统计看板 |
| `POST /api/medications/archive` | 一键归档 |
| `GET/POST/DELETE /api/plans...` | 用药方案管理 |
| `GET/POST /api/memos`, `DELETE /api/memos` | 备忘录管理 |
| `GET/POST /api/moods` | 心情记录 |
| `POST /api/social/like`, `GET /api/social/like/status` | 点赞 / 状态 |
| `GET/POST/DELETE /api/social/comments` | 评论管理 |
| `GET/POST /api/inventory`, `PUT /api/inventory/{name}` | 药品库存管理 |

## 🌱 未来展望：从工具到社区

Cyber-Tunnel 现在的目标是「把你的用药情况管明白」。而我们真正想做的，是把它**上线变成一个开放、温暖、真实的健康社区**，让更多人和自己的用药情况诚实相处，也彼此联结、互相支持。

### 我们想做的方向 🚀

1. **正式上线 & 多端适配**
   - 部署到云端，告别 localhost，用手机也能随时记录、随时刷。
   - 打磨响应式布局与主题皮肤，让它更好用、更好看。

2. **更专业的用药统计**
   - 每位成员的个人健康报告（月度 / 季度用药概览）。
   - 过量风险提醒与用药间隔、重复用药预警。
   - 与药品数据库联动，自动校验剂量是否在安全范围。

3. **真正的社区连接**
   - 更丰富的内容形态：图文分享、心情树洞、量化指标、康复故事。
   - 关注 / 好友 / 私信，构建彼此支持的健康圈。
   - 匿名互助小组、话题广场、结构化打卡。

4. **隐私与安全优先**
   - 严格的数据权限设计：谁看了我的记录、公开到哪一级都由我掌控。
   - 敏感健康数据的加密存储与合规审计（个人信息保护）。
   - 既鼓励分享，也坚决守住每个人「越界即停」的边界。

5. **温暖、克制、有责任**
   - 这不是一个鼓励「过量」的平台，而是一个**帮助你意识到风险、并科学管理用药**的地方。
   - 对处于困难中的用户，接入可靠的心理 / 医疗资源引导。
   - 社区氛围讲求真诚与善意，让每一次「求助」都不孤独。

> 我们相信：**诚实记录每一次吃药，是对自己最好的照顾；而把这份诚实分享出去，则能温暖更多人。** 🌍

如果你对这个社区有想法、有建议，欢迎加入我们，一起把这条赛博隧道修得更长、更亮。
